## 🎓 核心知识点速查（复习笔记）

### 1. 一维数组的定义与初始化
```c
int scores[10] = { 72, 85, 91, 68, 95, 78, 82, 88, 76, 90 };
//           ↑长度             ↑初始化列表
// 下标从 0 开始：scores[0] ~ scores[9]，没有 scores[10]！
```

### 2. 遍历数组 + 累加求和
```c
int sum = 0;
for (int i = 0; i < 10; i++)
{
    printf("%d ", scores[i]);   // 逐个输出
    sum += scores[i];            // 累加
}
printf("平均分：%.1lf", sum / 10.0);   // 除 10.0 转浮点，保留 1 位小数
```

### 3. 顺序查找（找目标值的下标）
```c
int target = 100;      // 要找的值
int index = -1;        // 找不到时保持 -1（哨兵）
for (int i = 0; i < 10; i++)
{
    if (scores[i] == target)
    {
        index = i;     // 记下第一个匹配的下标
        break;         // 找到一个就停
    }
}
```

### 4. 查找多个匹配下标（用另一个数组存）
```c
int index_arr[10];     // 存所有匹配下标
int match_count = 0;   // 计数器
for (int i = 0; i < 10; i++)
{
    if (scores[i] == target)
    {
        index_arr[match_count] = i;   // 存下标
        match_count++;                // 计数+1
    }
}
```

### 5. 冒泡排序（重点！双重 for）
```c
for (i = 0; i < 10 - 1; i++)            // 外层：轮数（n-1 轮）
{
    for (j = 0; j < 10 - 1 - i; j++)    // 内层：每轮少比一个
    {
        if (scores[j] > scores[j + 1])  // 前大后小就交换
        {
            temp = scores[j];
            scores[j] = scores[j + 1];
            scores[j + 1] = temp;
        }
    }
}
// 结果：从小到大排序
```
> 内层 `10 - 1 - i` 是关键：每轮结束最大的已沉底，不用再比。

### 6. 中位数
```c
if (n % 2 == 1)
    median = scores[n / 2];                      // 奇数个：中间那个
else
    median = (scores[n / 2 - 1] + scores[n / 2]) / 2.0;  // 偶数个：中间两个平均
```
> 先排序再求中位数；偶数个时一定要 `/2.0` 否则整数除法丢小数。

### 7. 找最大值（打擂台法）
```c
max = scores[0];              // 先假设第一个最大
for (i = 1; i < 6; i++)       // 从第二个开始比
{
    if (scores[i] > max)
        max = scores[i];      // 有更大的就更新
}
```
