## 🎓 核心知识点速查（复习笔记）

### 1. 函数的四要素
```c
返回值类型  函数名(参数列表)
{
    // 函数体
    return 值;       // 无返回值写 void，函数体内不用 return
}
```
- **定义**：函数本体写在哪
- **声明**：调用之前用一句话告诉编译器（`int max3(int a, int b, int c);`）
- **调用**：`result = max3(x, y, z);`

### 2. 为什么需要函数
- 一段逻辑反复用 → 封装一次到处调
- 主函数清爽，容易找 bug
- 期末考试写大题，分函数写得分点清晰

### 3. 常见算法函数模板

```c
// ① 素数判定（重点）
int prime(int m)
{
    if (m <= 1) return 0;
    if (m == 2) return 1;
    if (m % 2 == 0) return 0;
    for (int i = 3; i <= sqrt(m); i += 2)   // 只试奇数，到根号m
        if (m % i == 0) return 0;
    return 1;
}

// ② 各位数字之和
int sum_digits(int n)
{
    int sum = 0;
    while (n > 0)
    {
        sum += n % 10;    // 取最后一位
        n /= 10;          // 砍掉最后一位
    }
    return sum;
}

// ③ 幂函数（自己写 pow）
double mypow(double x, int n)
{
    double res = 1;
    for (int i = 0; i < n; i++)
        res *= x;
    return res;
}
```

### 4. 完全平方数的巧判定（4.cpp）
```c
// 数学原理：1+3+5+…+(2k-1) = k²
// 所以 n 依次减 1、3、5、7…，最后刚好减到 0 就是完全平方数
int IsSquare(int n)
{
    int odd = 1;
    while (n > 0) { n -= odd; odd += 2; }
    return n == 0 ? 1 : 0;
}
```

### 5. 结构体一次返回多个值（0.cpp）
```c
typedef struct {
    int first;
    int second;
} IntPair;

IntPair swap(int a, int b)
{
    IntPair res = { b, a };
    return res;
}
```
> 没有指针的时候，用结构体就能一次带回两个结果（这也是 swap 的早期写法）。
