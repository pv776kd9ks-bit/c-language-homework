## 🎓 核心知识点速查（复习笔记）

### 1. for 循环三要素
```c
for (i = 2; i <= 10; i++)   // (初始化表达式; 循环条件; 迭代更新)
{
    // 循环体
}
```

### 2. 偶数 / 奇数判断
```c
i % 2 == 0    // 偶数：对 2 取模等于 0
i % 2 != 0    // 奇数：对 2 取模不等于 0
```

### 3. continue vs break（重点易错）
```c
continue;   // 终止【本轮】剩余代码，跳到循环的 i++，继续下一轮
            // 不会退出整个 for 循环
break;      // 直接退出整个循环
```
> 课堂练习2 里：奇数被 `continue` 跳过打印，所以只剩偶数输出。

### 4. 嵌套 for 循环（九九乘法表）
```c
for (row = 1; row <= 9; row++)          // 外层：行
{
    for (col = 1; col <= row; col++)    // 内层：列，最多到 row
    {
        printf("%d*%d=%d\t", col, row, col * row);
    }
    printf("\n");                        // 每行结束换行
}
```
> 内层条件 `col <= row` 保证乘法表是"下三角"形状。

### 5. while 循环 + 哨兵值（-1 结束输入）
```c
scanf_s("%d", &score);
while (score != -1)          // 输入 -1 时结束循环
{
    // 处理成绩
    scanf_s("%d", &score);   // 循环内再次读入，否则死循环
}
```
> 用 `-1` 这种"不可能出现的值"作为结束标志，叫**哨兵值（sentinel）**。

### 6. 累加 + 计数求平均
```c
sum += score;   // 累加总分
count++;        // 统计人数
ave = sum * 1.0 / count;   // 乘 1.0 转成小数运算，避免整数除法
```
> 整数除以整数会丢小数，`sum * 1.0` 是常用的转浮点技巧。

### 7. 数据有效性检查
```c
if (score >= 0 && score <= 100)  // 只统计 0~100 的有效成绩
```
> 输入非法时提示并跳过，避免脏数据污染统计结果。

1. 用 Visual Studio 打开 `Homework3.slnx`
