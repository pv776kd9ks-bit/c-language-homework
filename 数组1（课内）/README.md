# 数组1（课内）— 一维数组专题作业

> 大一《C 语言程序设计》课内练习，Visual Studio 2022 编写，`.cpp` 后缀（语法为 C 语言）。
> 本目录共 8 道题，全部围绕**一维数组**：遍历、查找、求极值、交换、计数、移位。

---

## 📋 题目与知识点

| 文件 | 题目 | 考查知识点 |
|------|------|-----------|
| `1.cpp` | 输入 n 和 n 个整数，把数组逆序后输出 | 首尾对调 `a[i] ↔ a[n-1-i]`、只需循环 `n/2` 次、中间变量 |
| `2.cpp` | 在 n 个数中查找 x，输出它所在的下标；找不到输出"未找到" | 顺序查找、`index = -1` 作"没找到"标记、`if (index != -1)` 判断 |
| `3.cpp` | 输出斐波那契数列前 46 项，每 5 项换一行 | 递推 `a[i] = a[i-1] + a[i-2]`、前两项都要赋初值、`(i+1) % 5 == 0` 控制换行 |
| `4.cpp` | 输入 n 个数，找出最小元素的下标，并把它与 `a[0]` 交换 | 用 `index` 记录**下标**而不是值、三变量交换 |
| `5.cpp` | 投票统计：n 次投票，栏目编号 1~8，统计各栏目得票数 | 数组当**计数器** `count[x]++`、越界值打印 `invalid`、表格化输出 |
| `6.cpp` | 12 个元素的数组，把第 8 个元素移到最前面，其余依次后移 | 先保存被覆盖的元素 `m = a[7]`、倒序搬移 `a[i+1] = a[i]`、最后补 `a[0] = m` |
| `7.cpp` | 输入 5 个数，求最大值、最小值，并倒序输出 | 打擂台法求极值、倒序输出 `for (i = n-1; i >= 0; i--)` |
| `8.cpp` | 输入 12 个数，求最大值下标、最小值下标 | 下标记录法（⚠️ 本题写法有缺陷，见下文） |

## 🎯 核心速查

### 1. 数组逆序（首尾对调）
```c
for (int i = 0; i < n / 2; i++)     // 只走一半！走全程等于换回去
{
    int m = a[i];
    a[i] = a[n - 1 - i];
    a[n - 1 - i] = m;
}
```
> 注意区分：**逆序输出**（只倒着打印，数组本身不变）和 **逆序存放**（数组内容真的被换了）。

### 2. 顺序查找 + 标记
```c
int index = -1;                     // -1 表示"还没找到"
for (int i = 0; i < n; i++)
    if (a[i] == x) { index = i; break; }   // 找第一个就 break

if (index != -1) printf("%d", index);
else             printf("未找到");
```
> 不加 `break` 时记录的是**最后一次**出现的位置；题目要"第一次出现"就必须加 `break`。

### 3. 求极值：打擂台法
```c
int max = a[0];                     // ⚠️ 初值放循环外！从第 1 个开始比
for (int i = 1; i < n; i++)
    if (a[i] > max) max = a[i];
```
> **要下标就把值的位置换成下标：**
> ```c
> int index_max = 0;
> for (int i = 1; i < n; i++)
>     if (a[i] > a[index_max]) index_max = i;
> ```

### 4. 数组当计数器（投票统计）
```c
int count[9] = { 0 };               // 栏目编号 1~8 → 数组要开 9 个（下标 0 空着）
if (x >= 1 && x <= 8) count[x]++;   // 先判合法，再计数
else                  printf("invalid: %d\n", x);
```
> 数组长度按**最大下标 + 1** 开：编号最大是 8，所以至少 `count[9]`。

### 5. 数组移位：先存后搬
```c
int m = a[7];                       // ① 先把要被覆盖的元素存起来
for (int i = 6; i >= 0; i--)        // ② 从后往前搬，避免覆盖未搬的数据
    a[i + 1] = a[i];
a[0] = m;                           // ③ 最后补到最前面
```
> 往前搬（`a[i-1] = a[i]`）时要从前往后遍历，方向反了数据就被冲掉了。

### 6. 斐波那契递推
```c
a[0] = 1; a[1] = 1;                 // 前两项必须手动赋初值
for (int i = 2; i < 46; i++)
    a[i] = a[i - 1] + a[i - 2];
```
> 46 项时 `a[45]` 约为 18 亿，仍在 `int` 范围内（约 21 亿），47 项就会溢出到负数。

## 🔍 易错点自查（本题组）

| 序号 | 坑 | 正确做法 |
|------|----|---------|
| 1 | 求极值的变量在循环里被重置 | 初值 `max = a[0]` / `index = 0` 写在 for **外面**，循环内只做比较更新 |
| 2 | 循环里加了奇怪的 `break` 条件 | 除"找到目标就停"外，遍历途中不应随意 `break` |
| 3 | 逆序循环写了 `n` 次 | 首尾对调只走 `n/2` |
| 4 | 计数器数组开小了 | 编号 1~8 → `count[9]`，越界写会崩 |
| 5 | 移位方向反了 | 往后搬从后往前遍历；往前搬从前往后遍历 |
| 6 | 忘记保存被覆盖的元素 | 移位前先 `int m = a[7]` |
| 7 | 数组下标从 1 数起 | 下标从 **0** 开始，n 个元素的最后一个下标是 `n-1` |

### 8.cpp 的具体问题（值得重点看）

```c
for (int i = 0; i < 12; i++)
{
    index_max = 0;                  // ❌ 每轮都重置，上一轮的结果白记了
    if (a[i] > a[index_max]) index_max = i;
    else if (a[i] == a[0]) break;   // ❌ 碰到和 a[0] 相等的元素就提前退出
}
```

两个缺陷：
1. **`index_max = 0` 写在循环体内** → 每一轮都把记录清零，只能记住"本轮"的比较结果；
2. **`else if (a[i] == a[0]) break`** → 只要数组里有一个数等于首元素，循环就提前终止，后面的最大值直接漏掉。

`index_min` 那段是同样的问题。

正确写法：

```c
int index_max = 0, index_min = 0;
for (int i = 1; i < 12; i++)        // 从 1 开始，0 已经是擂台主
{
    if (a[i] > a[index_max]) index_max = i;
    if (a[i] < a[index_min]) index_min = i;
}
printf("最大值下标：%d，最小值下标：%d\n", index_max, index_min);
```
> 一个循环就能同时求出两个下标，不需要写两遍。
