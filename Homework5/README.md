## 🎓 核心知识点速查（复习笔记）

### 1. 字符串比较：strcmp（重点）
```c
#include <string.h>

strcmp(字符串1, 字符串2);
// 返回值：
//   == 0  → 两个字符串相等
//   > 0   → 字符串1 大于 字符串2（按字典序）
//   < 0   → 字符串1 小于 字符串2
```
> **字符串不能用 `==` 比较**（那是在比地址），必须用 `strcmp`。

### 2. 二维字符数组存多个字符串
```c
char arr[3][20] = { "zhangsan", "lisi", "wangwu" };
//    ↑3个字符串   ↑每个最长19字符（留1个给 \0）
// 取出第 i 个字符串：arr[i]（就是一个字符串，可直接给 strcmp 用）
```

### 3. 登录校验模板（遍历 + strcmp + 标记）
```c
int result = 0;                       // 0=没找到
for (int i = 0; i < 3; i++)
{
    if (strcmp(arr[i], input) == 0)   // 匹配成功
    {
        result = 1;
        break;                        // 找到了就停
    }
}
if (result == 1) printf("用户存在，登录成功");
else             printf("用户不存在");
```

### 4. scanf_s 读字符串要带长度
```c
scanf_s("%s", input, (unsigned int)sizeof(input));
//                        ↑必须给缓冲区大小，否则 VS 报 C6054/编译错
// 普通 scanf 写法：scanf("%s", input);
```

### 5. 二维数组遍历（行=学生，列=科目）
```c
int scores[3][4] = { {88,76,90,82}, {95,82,78,90}, {72,85,88,76} };

for (i = 0; i < 3; i++)      // 外层：行（第几个学生）
{
    sum = 0;                  // 每行开始前清零！
    for (j = 0; j < 4; j++)   // 内层：列（第几科）
    {
        sum += scores[i][j];
    }
    printf("总分：%d", sum);
}
```
> 求**每行**的总和：`sum = 0` 必须放在外层循环**里面**，否则会把上一行累加进来。

### 6. 字符数组初始化（存密码）
```c
char src[20] = "admin123";   // 自动补上结尾的 '\0'
```
