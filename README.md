## 🎓 核心知识点速查（复习笔记）

### 1. 输入输出
```c
scanf("%d", &a);      // 输入整数（变量前必须加 &）
scanf("%lf", &r);     // 输入 double 小数（注意是字母 L，不是数字 1）
printf("%d", a);      // 输出整数（不加 &）
printf("%.2f", c);    // 保留 2 位小数
printf("%%");         // 输出百分号要写两个 %%
```
> ⚠️ `scanf_s` 是 VS 专属函数，提交到标准编译器会报错，应改用 `scanf`，并在文件首行加 `#define _CRT_SECURE_NO_WARNINGS 1` 消除警告。

### 2. 取位运算（以三位数 a 为例）
```c
百位：a / 100
十位：(a % 100) / 10
个位：a % 10
```
> 整数除法 `/` 直接舍去小数，`%` 取余数。

### 3. 闰年判断
```c
(Y % 4 == 0 && Y % 100 != 0) || Y % 400 == 0
```
- 能被 4 整除 **且** 不能被 100 整除；**或** 能被 400 整除。

### 4. `#define` 宏定义
```c
#define PI 3.14      // 宏定义不能写等号！名字和值之间用空格
```

### 5. 勾股定理（斜边）
```c
c = sqrt(a * a + b * b);   // 需要 #include <math.h>
```
> `sqrt()` 只接受 1 个参数。

## ▶️ 如何运行

1. 用 Visual Studio 打开 `Homework1.slnx`
2. 在「源文件」中**只保留一个带 `main()` 的文件参与编译**（右键其他 cpp → 属性 → 从生成中排除 → 是），否则报"多个 main 函数"错误
3. 点绿色三角「本地 Windows 调试器」运行
