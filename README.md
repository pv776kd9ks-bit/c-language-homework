## 🎓 核心知识点速查（复习笔记）

### 1. 输入输出
```c
scanf("%d", &a);      // 输入整数（变量前必须加 &）
scanf("%lf", &r);     // 输入 double 小数（注意是字母 L，不是数字 1）
printf("%d", a);      // 输出整数（不加 &）
printf("%.2f", c);    // 保留 2 位小数
printf("%%");         // 输出百分号要写两个 %%
```
> ⚠️ `scanf_s` 是 VS 专属函数，提交到标准编译器会报错，应改用 `scanf`，并在文件首行加 `#define _CRT_SECURE_NO_WARNINGS 1` 消除警告。

### 2. 取位运算（以三位数 a 为例）
```c
百位：a / 100
十位：(a % 100) / 10
个位：a % 10
```
> 整数除法 `/` 直接舍去小数，`%` 取余数。

### 3. 闰年判断
```c
(Y % 4 == 0 && Y % 100 != 0) || Y % 400 == 0
```
- 能被 4 整除 **且** 不能被 100 整除；**或** 能被 400 整除。

### 4. `#define` 宏定义
```c
#define PI 3.14      // 宏定义不能写等号！名字和值之间用空格
```

### 5. 勾股定理（斜边）
```c
c = sqrt(a * a + b * b);   // 需要 #include <math.h>
```
> `sqrt()` 只接受 1 个参数。

### 6. 自增自减：前缀 vs 后缀（Homework2 易错点）
```c
printf("%d", a++);   // 先输出 a 原来的值，再 +1
printf("%d", ++a);   // 先 +1，再输出新值
```
> 一句话：`++` 在变量**前面**就先加后用，在变量**后面**就先用后加。

### 7. 强制类型转换（Homework2 易错点）
```c
y = (int)x;          // 把 double 转成 int，直接截断小数部分（不是四舍五入）
z = x - (int)x;      // 原数减整数部分 = 小数部分
```

### 8. continue vs break（Homework3 易错点）
```c
continue;   // 终止【本轮】剩余代码，跳到 i++ 继续下一轮（不退出循环）
break;      // 直接退出整个循环
```

### 9. while 循环 + 哨兵值（Homework3 重点）
```c
while (score != -1)        // 输入 -1 结束循环
{
    sum += score;          // 累加
    count++;               // 计数
    scanf_s("%d", &score); // 循环内再读，否则死循环
}
ave = sum * 1.0 / count;   // 乘 1.0 转浮点，避免整数除法丢小数
```

### 10. 数组：遍历 / 查找 / 排序（Homework4 重点）
```c
// 遍历+累加
for (i = 0; i < 10; i++) { printf("%d ", a[i]); sum += a[i]; }

// 顺序查找目标值下标（找不到保持 -1）
if (a[i] == target) { index = i; break; }

// 冒泡排序（从小到大）
for (i = 0; i < n - 1; i++)
    for (j = 0; j < n - 1 - i; j++)
        if (a[j] > a[j + 1]) { temp = a[j]; a[j] = a[j + 1]; a[j + 1] = temp; }
```
> 数组下标从 0 开始，**越界（如 a[n]）是经典 bug**；求平均要 `/ n * 1.0` 或 `/ n.0` 避免整数除法。

### 11. 字符串比较与二维字符数组（Homework5 重点）
```c
#include <string.h>

strcmp(s1, s2);        // 字符串比较：== 0 相等（字符串不能用 == 比！）
char arr[3][20] = { "zhangsan", "lisi", "wangwu" };   // 存 3 个字符串

scanf_s("%s", input, (unsigned int)sizeof(input));    // 读字符串要带长度

// 登录校验模板：遍历 + strcmp + 标记
int ok = 0;
for (i = 0; i < 3; i++)
    if (strcmp(arr[i], input) == 0) { ok = 1; break; }
```

### 12. 二维数组按行求和（Homework5 易错点）
```c
for (i = 0; i < 3; i++)   // 行
{
    sum = 0;              // ⚠️ 每行开始前必须清零
    for (j = 0; j < 4; j++)
        sum += scores[i][j];
}
```

### 13. 三变量交换与三数排序（Week4作业 重点）
```c
// 两数交换：c = b; b = a; a = c;
// 三数从小到大：
if (a > b) { temp = a; a = b; b = temp; }
if (a > c) { temp = a; a = c; c = temp; }
if (b > c) { temp = b; b = c; c = temp; }
```

### 14. switch 多 case 合并与 default（Week4作业 重点）
```c
switch (month)
{
    case 3: case 4: case 5:  printf("spring"); break;   // 多个 case 共用 break
    ...
    default: pay = price; break;   // 兜底：没列出的情况
}
```
> 字符范围判断：`ch >= '0' && ch <= '9'`（数字）、`ch >= 'A' && ch <= 'Z'`（大写）。

### 15. for 循环：累加 / 累乘 / 枚举（for循环作业 重点）
```c
// 累加：sum += 1.0 / (2 * i - 1);   ⚠️ 写 1.0 避免整数除法
// 累乘（阶乘）：double m = 1; m *= i;   ⚠️ 初值必须是 1
// 枚举筛选：if (i % 6 == 0 && i % 5 != 0) sum += i;
// 水仙花数：bai=i/100; shi=i/10%10; ge=i%10; 立方和==本身
```
