## 🎓 核心知识点速查（复习笔记）

### 1. 赋值表达式有"值"
```c
b = a + 1;        // 表达式 (b=a+1) 的值就是赋给 b 的那个数
printf("%d", b = a + 1);   // 可以直接在 printf 里赋值并输出
```
> 赋值表达式本身的值 = 赋完之后的左值结果。

### 2. 连等赋值：从右往左
```c
x = y = a + 2;    // 先算 a+2，赋给 y，再把 y 的值赋给 x
// 等价于 y = a+2; x = y;
```

### 3. 交换两个变量（经典 temp 法）
```c
temp = m;   // 先把 m 存起来
m = n;      // m 拿到 n 的值
n = temp;   // n 拿到原来 m 的值
```
> 没有 temp 直接 `m=n; n=m;` 会丢值，因为 m 已被覆盖。

### 4. 复合赋值运算符
```c
a += b;   // a = a + b
a -= b;   // a = a - b
a *= b;   // a = a * b
a /= b;   // a = a / b
a %= b;   // a = a % b（注意：printf 输出 % 要写 %%，如 printf("a%%=b->%d\n", a %= b)）
```
> 复合赋值会**改变 a 本身**，且 `a /= b` 中 b 不能为 0。

### 5. 自增自减：前缀 vs 后缀（重点易错）
```c
printf("%d", a++);   // 先输出 a 原来的值，再 +1
printf("%d", ++a);   // 先 +1，再输出新值
printf("%d", a--);   // 先输出，再 -1
printf("%d", --a);   // 先 -1，再输出
```
> 一句话：`++` 在变量**前面**就先加后用，在变量**后面**就先用后加。

### 6. 强制类型转换
```c
y = (int)x;          // 把 double 的 x 转成 int，丢掉小数部分
z = x - (int)x;      // 原数减整数部分 = 小数部分
printf("%f", z);     // 小数部分用 %f 输出
```
> `(int)` 只是**临时转换**，x 本身类型不变；小数部分直接截断，不是四舍五入。

### 7. switch 判断月份天数（课上练习）
```c
switch (b) {           // b 是月份
    case 1: case 3: case 5: case 7: case 8: case 10: case 12:
        printf("31天\n"); break;   // 大月
    case 4: case 6: case 9: case 11:
        printf("30天\n"); break;   // 小月
    case 2:                          // 二月看闰年
        if (闰年) printf("29天\n"); else printf("28天\n");
        break;
}
```
> 多个 case 可以**堆在一起共享同一段代码**；每个 case 结尾记得 `break;`，否则会"穿透"继续往下执行。

### 8. 闰年判断（再次复习）
```c
(a % 4 == 0 && a % 100 != 0) || (a % 400 == 0)
```

## ▶️ 如何运行

1. 用 Visual Studio 打开 `Homework2.slnx`
2. **注意：本作业中 1.cpp ~ 5.cpp 和 课上练习1.cpp 的 `main()` 都被 `/* */` 注释掉了**，默认只有 `6.cpp` 能编译运行
3. 想看某道题，就把那个文件的注释解开（删掉 `/*` 和 `*/`），同时把其他文件的 `main()` 注释掉，避免"多个 main 函数"错误
4. 点绿色三角「本地 Windows 调试器」运行
