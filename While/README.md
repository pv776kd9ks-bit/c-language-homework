## 🎓 核心知识点速查（复习笔记）

### 1. while 循环（先判断后执行）
```c
int i = 1;                 // ① 初始化（循环外）
while (i <= n)             // ② 条件
{
    sum += 1.0 / (2*i-1);  // ③ 循环体
    i++;                   // ④ 迭代更新 —— ⚠️ 忘了就是死循环！
}
```
> 与 for 对比：`for` 把"初始化/条件/迭代"写在一行；`while` 拆开写，**迭代语句容易漏**。

### 2. do-while 循环（先执行后判断，至少执行一次）
```c
do
{
    printf("input:");
    scanf_s("%d", &m);
    if (m == n) { printf("Unlocked!"); break; }
    tries++;
} while (m != n);          // ⚠️ 结尾有分号！
```
> 猜数字/密码输入这类"至少先问一次"的场景，天然适合 do-while。

### 3. 幂的两种写法
```c
// 方法一：累乘（自己写循环）
sum = 1;                   // 初值 1
while (i <= n) { sum *= x; i++; }     // x 乘 n 次 = x^n

// 方法二：pow() 函数
#include <math.h>
m = pow(2, i);             // 2 的 i 次方
```

### 4. 数字反转（经典必考题）
```c
int rev = 0;
while (n > 0)
{
    rev = rev * 10 + n % 10;   // 新数 = 旧数×10 + 当前个位
    n /= 10;                   // 砍掉个位
}
// 例：n=1234 → rev=4321
```

### 5. 查找类问题的标记变量
```c
int found = 0;             // 0 = 还没找到
...
if (找到) { found = 1; break; }
...
if (found == 0) printf("No even found\n");
```

## ⚠️ 本作业待办提醒

- 除 `8.cpp` 外，1~7 的 `main()` 都被注释，需要取消注释才能单独运行；
- `6.cpp` 逻辑可简化：第一段 while 找到第一个偶数后 `break`，第二段继续读剩余数找更大偶数——运行没问题，但代码偏绕，复习时可以重写为单循环 + `found` 标记；
- `3.cpp` 循环体是 `sum *= x`（算 x^n），但输出写的是 `"!n=%.0f"`，提示文字与结果含义不符，实际输出的是 x 的 n 次方，注意区分。
