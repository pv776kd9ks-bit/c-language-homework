## 🎓 核心知识点速查（复习笔记）

### 1. for 循环三要素
```c
for (int i = 1; i <= n; i++)   // (初始化; 条件; 迭代)
{
    // 循环体
}
```

### 2. 累加求和（注意小数陷阱）
```c
double sum = 0;
sum += 1.0 / (2 * i - 1);   // ⚠️ 必须写 1.0，写 1 就是整数除法（结果为 0）
```
> 整数除法会丢小数，`1.0 / k` 才能得到小数结果。

### 3. 累乘（阶乘）
```c
double m = 1;        // 累乘初值必须是 1（0 乘任何数都是 0）
for (i = 1; i <= n; i++)
    m *= i;          // m = m * i
```
> 阶乘结果可能很大，用 `double` 更保险。

### 4. 枚举 + 条件筛选求和
```c
for (i = 50; i <= 200; i++)
{
    if (i % 6 == 0 && i % 5 != 0)   // 能被 6 整除 且 不能被 5 整除
        sum += i;
}
```

### 5. 取位运算（水仙花数）
```c
bai = i / 100;        // 百位：整除 100
shi = i / 10 % 10;    // 十位：先除 10 再取余 10
ge  = i % 10;         // 个位：取余 10

if (bai*bai*bai + shi*shi*shi + ge*ge*ge == i)
    printf("%d\n", i);   // 各位立方和等于本身 → 水仙花数
```
> 三位水仙花数：153、370、371、407。

### 6. pow() 幂函数
```c
#include <math.h>
x = pow(2, i);        // 2 的 i 次方
```
